# Paul Gould

Founder/operator building products around games, markets, and communities.

I am currently focused on [PokerWorks](https://pokerworks.io), a poker platform company working on real-time play-money poker, transparent fairness, and tools for people who build, study, and run poker games.

I also run [Trade2Win](https://www.trade2win.com), a long-running online community for financial traders. Previously I owned and ran Replay Gaming, the company behind Replay Poker; the Replay Poker IP was sold to Legend in 2020. Legend later agreed to be acquired by Genius Sports in a transaction valued at up to $1.2B.

## Current Work

- [Awesome Poker](https://github.com/pokerworks/awesome-poker) - A curated list of poker software, research, tools, datasets, and learning resources.
- [PokerWorks Lab](https://pokerworks.io/lab/) - Poker tools, calculators, references, and open community resources.
- Poker platform architecture: engines, hand histories, fairness, observability, and reliable real-time systems.

## Background

I have founded, operated, advised, and invested in internet businesses across trading, social gaming, media, communities, and software.

Earlier work includes Dynamite Partners, a London web studio; Nudge Social Media, a social media agency; ForexDesk, a platform for forex traders; and NSider2, a large Nintendo community that was later acquired.
